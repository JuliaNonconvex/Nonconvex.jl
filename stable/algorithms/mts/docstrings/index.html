NonconvexSearch.LS1Alg — Type
LS1Alg()

A pure-Julia local search algorithm using a single trajectory (LS1). Supports only box-constrained continuous problems with finite bounds; equality and inequality constraints are unsupported. Options are set through LS1Options.

NonconvexSearch.LS1Options — Type
LS1Options(; kwargs...)

Options for LS1Alg. The main tunable fields are:

  • M: the number of initial solutions,
  • maxiter: the maximum number of outer iterations,
  • search_range_tol: the search range tolerance used as a stopping criterion,
  • BONUS1, BONUS2: bonus values used when updating the best solution.

The remaining fields are fixed parameters of the algorithm and should not normally be changed.

NonconvexSearch.MTSAlg — Type
MTSAlg()

The Multiple Trajectory Search gradient-free global optimization algorithm (Tseng and Chen, 2008), implemented in pure Julia. Supports only box-constrained continuous problems with finite bounds; equality and inequality constraints are unsupported. Options are set through MTSOptions.

NonconvexSearch.MTSOptions — Type
MTSOptions(; kwargs...)

Options for MTSAlg. The main tunable fields are:

  • M: the number of trajectories,
  • maxiter: the maximum number of outer iterations,
  • search_range_tol: the search range tolerance used as a stopping criterion,
  • n_foreground: the number of trajectories in the foreground set,
  • n_local_search, n_local_search_test, n_local_search_best: iteration budgets of the local search phases,
  • BONUS1, BONUS2: bonus values used when updating the best solution,
  • a_min, a_max, b_min, b_max, c_min, c_max: parameter ranges for the randomized search directions.

The remaining fields are fixed parameters of the algorithm and should not normally be changed.

NonconvexSearch.RCDAlg — Type
RCDAlg(sub_alg)

Random coordinate descent meta-algorithm. Each iteration selects a random subset of the coordinates and solves the subproblem over those coordinates with sub_alg, keeping the remaining coordinates fixed. sub_alg can be any AbstractOptimizer from the Nonconvex ecosystem.

NonconvexSearch.RCDOptions — Type
RCDOptions(; kwargs...)

Options of the random coordinate descent meta-algorithm. The fields are:

  • maxiter: the maximum number of outer iterations.
  • fraction: the fraction of coordinates updated in each iteration. Ignored when ncoords is set.
  • ncoords: the number of coordinates updated in each iteration. When nothing, fraction is used.
  • sub_options: the options passed to the sub-solver. When nothing, the sub-solver's default options are used.
  • verbose: whether to print the objective in every iteration.
NonconvexSearch.rcd_submodel — Method
rcd_submodel(model, x, coords)

Builds a VecModel over the selected coordinates coords with the other coordinates of x substituted in the objective and constraints.
