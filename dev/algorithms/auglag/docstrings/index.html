NonconvexPercival.AugLag — Type
AugLag

Alias for PercivalAlg, kept for backwards compatibility with the original Nonconvex.@load AugLag name. Note that the Julia-native AugLagAlg from NonconvexAugLab.jl is a different, newer algorithm.

NonconvexPercival.AugLagOptions — Type
AugLagOptions

Alias for PercivalOptions, kept for backwards compatibility.

NonconvexPercival.PercivalAlg — Type
PercivalAlg()

The Percival.jl augmented Lagrangian algorithm for nonlinear programming, exposed through the Nonconvex interface. It supports nonlinear inequality and equality constraints and box constraints, and can work in first-order mode (limited-memory quasi-Newton) or second-order mode. Options are set through PercivalOptions.

The alias AugLag refers to the same algorithm.

NonconvexPercival.PercivalOptions — Type
PercivalOptions(; first_order=true, memory=5, backend::Symbol=:zygote, kwargs...)

Options for PercivalAlg, passed to optimize as options = ....

  • first_order: when true (default) the subsolver uses a limited-memory quasi-Newton Hessian approximation (first-order mode); when false, exact Hessians are used (second-order mode).
  • memory: the limited-memory size of the quasi-Newton approximation.
  • backend: the AD backend for derivatives, :zygote (default) or :auto.

All remaining keyword arguments are forwarded to Percival (tolerances, stopping criteria, etc.); see the Percival documentation.

The alias AugLagOptions refers to the same options type.

NonconvexPercival.percival_callback — Method
percival_callback(callback)

Adapts the Nonconvex callback to Percival's callback(nlp, solver, stats) signature. The Nonconvex callback receives a Solution carrying the current iterate, the objective value, and the primal/dual feasibility in the convergence state.
