Nonconvex.jl

Nonconvex.jl is a Julia toolbox for gradient-based and gradient-free constrained optimization. It assembles the packages of the JuliaNonconvex ecosystem behind one consistent modelling and optimization interface.

What is in these docs

  • General — the modelling and automatic differentiation core provided by NonconvexCore.jl and re-exported by Nonconvex: Model and DictModel for flat and named variables, objectives, constraints, the solver capability system and the DifferentiationInterface-based AD machinery. The Gradients, Jacobians and Hessians guide covers user-defined derivatives, ChainRules in ForwardDiff and gradient tracing, and Loading algorithm packages documents the @load macro used to install algorithm packages on demand.
  • Algorithms — wrappers around well-known optimizers such as Ipopt, NLopt, MMA, Percival, Juniper, Pavito, NOMAD and TOBS, and pure-Julia methods such as metaheuristics, Bayesian optimization, multi-start, multiple trajectory search, semidefinite programming and augmented Lagrangian. See the algorithm overview for the full capability table.

Installation

using Pkg
Pkg.add("Nonconvex")

Algorithm packages are installed on demand with the @load macro: Nonconvex.@load Ipopt installs and loads NonconvexIpopt.jl, and likewise for MMA, NLopt, Bayesian, Metaheuristics, and the rest of the algorithm packages.

Quick start

Minimize the Rosenbrock function using Ipopt:

using Nonconvex
Nonconvex.@load Ipopt

f(x) = (x[1] - 1.0)^2 + 100.0 * (x[2] - x[1]^2)^2
model = Model(f)
result = optimize(model, IpoptAlg(), [-1.0, 1.0])

result.minimum    # ≈ 0.0
result.minimizer  # ≈ [1.0, 1.0]

A DictModel works the same way with named variables, and JuMP models can be converted with DictModel(jump_model) when JuMP is loaded. Inequality, equality and semidefinite constraints are added with add_ineq_constraint!, add_eq_constraint! and add_sd_constraint! respectively.
